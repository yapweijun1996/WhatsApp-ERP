# Roadmap

## V1 — Demo Proof
QR adapter + Pi Agent + GPT Gateway + deterministic ERP Demo + automated quotation + customer acceptance + Draft SO + human post/confirmation simulation.

## V1.1 — Reliability
Session recovery, richer exceptions, media/voice normalization, stronger customer-specific memory, observability, replay fixtures.

## V1.2 — Official Channel
Add Meta Cloud API adapter without changing core contracts; production webhook/auth/template/rate-limit handling.

## V2 — ERP Adapters
Read-first real ERP connector, then governed Draft SO integration. Keep posting behind explicit business permissions.

## V3 — Selective Autonomy
Only evidence-backed low-risk repeat-order cases may reduce staff effort; commercial posting boundary changes require separate owner decision and audit redesign.
